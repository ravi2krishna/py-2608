    -> Operators

        -> Operators are special "Symbols" and "keywords", which Performs 
        Operations on Variables and their Values.

        -> There are different types of operators, to deal with different types of data 

        -> Arithmetic Operators 

            -> To Perform Mathematical Calculations 

                -> + - * / % 

                -> // - floor division (same as division but rounds off result)
                -> ** - Exponentiation (same as calculating powers)

        -> Compound Assignment Operators         

            -> Assignment Operator is = (used for assigning a value to Variable)

            -> Compound Assignment Operators Combine Arithmetic Operators 
            with Assignment Operators for "short hand code" (concise code)

                -> x = 10 
                
                -> x = x + 5 (long form)
                -> x = x * 5 (long form)

                -> x += 5 (short form)
                -> x *= 5 (short form)

                -> NOTE: x = x + 5 and x += 5 both does same Operation

            -> In Other Programming Languages, We got Increment & Decrement Operators

                -> Increment (++) - Increase the value 
                -> Decrement (--) - Decrease the value 

                -> NOTE: Above Operators are not supported in python 


        -> Comparison Operators 

            -> Comparison Operators are used for Comparing Values
            and result is in boolean type (True/False)

            -> Used in Conditional Checks 

                -> ==, !=, >, <, >=, <= 

        -> Logical Operators 

            -> Logical Operators are used for Performing Logical Operations

            -> Used to check multiple conditions and result is in boolean type (True/False)

                -> and : if both conditions are True, then only result is True, otherwise False 
                -> or : if one of the conditions is True, then result is True, otherwise False 
                -> not : negates the result, if true then false and vice versa  

                            X       Y       X and Y    X or Y    not X    not Y
                            T       T           T         T         F       F
                            T       F           F         T         F       T
                            F       T           F         T         T       F
                            F       F           F         F         T       T 


        -> Membership Operators 

            -> Used for checking if an object in in the given sequence 

                -> in: return True, if given object is in sequence

                -> not in: return True, if given object is not in sequence

        
        -> Identity Operators 

            -> Used to check if objects are same 

                -> is: return True, if objects are same  
                
                -> is not: return True, if objects are not same  

            -> NOTE: 
            
                -> (Equality operator ==): Compares the values of two objects. 
                It returns True if their contents are the same, 
                regardless of where they are stored in memory.

                -> is (Identity operator): Compares the identity (memory address) of two objects. 
                It returns True only if both variables refer to the exact same object in memory. 


        -> Bitwise Operators 

            -> Used in Low Level Programming (1010101011)

                -> & - if both bits are 1, then result is 1 
                -> | - if one of the bits is 1, then result is 1 
                -> etc

    -> Accessing Strings 

        -> Indexing 

            -> String indexing in Python allows access to "individual characters within a string" 
            using their "position", known as the "index".

            -> Python uses zero-based indexing, meaning the first character is at index 0, 
            the second at index 1, and so on.

                -> print(string[index])

            -> Positive Indexing:
            Starts from the beginning of the string.
            The index of the first character is 0.
        
            -> Negative Indexing:
            Starts from the end of the string.
            The index of the last character is -1.

            -> text = "python"

            0 1 2 3 4    5
            p y t h o    n 
           -6 -5 -4 -3 -2 -1

        -> NOTE: Accessing index out of range will cause Error

        what operations you can perform on a datatype

        -> NOTE: we have len() function, which helps you know
        number of items in container

    
    -> Slicing

        -> String slicing in Python is a method for extracting a portion (substring) 
        from a larger string. It utilizes the slice operator [] with specific 
        indices to define the desired segment.

        -> syntax 

            string[start:end:step]

                -> start (optional): The index where the slice begins (inclusive). 
                    If omitted, it defaults to 0 (the beginning of the string).
                -> end (optional): The index where the slice ends (exclusive). 
                    The character at this index is not included. 
                    If omitted, it defaults to the length of the string (the end of the string).
                -> step (optional): The increment between each index during slicing. 
                    If omitted, it defaults to 1. 
                    A negative step value can be used to slice in reverse.
            
            -> Earlier we used range()

                range(start,end,step)

    -> Abstraction 

        -> Abstraction in OOP is a principle that involves "hiding" complex "implementation" 
        details and showing only the essential features of an object to the user.

        -> Hiding implementation: means "hiding the internal workings" of an object 
        and present a simplified view. 
        
        -> For example, when using an ATM, 
        you only  interact with a simple interface (card, PIN, cash dispenser) without needing 
        to know the complex process of backend banking operations that occur. 

    
    -> How To achieve Abstraction In Python 

        -> Using Abstract Class 

        -> NOTE: Till now what ever the classes we created so far, are Concrete Classes 

        -> An Abstract Class In Python Functions as a "blueprint" for Other Classes,
        defining a common structure that subclasses must adhere to.

        -> Abstract Class cannot be instantiated directly, meaning you 
        cannot create objects to Abstract Class 

        -> NOTE: Abstract Classes help you enforce Contract Like Behaviors

        -> Abstract classes are Implemented in Python Using 
        "abc" module (Abstract Base Class)

            -> from abc import ABC, abstractmethod 

        -> NOTE: To Achieve abstraction, Create a class that inherits from ABC, 
        inside this class define one or more abstract methods using @abstractmethod decorator  

            -> NOTE: abstract methods have declarations, but no implementation 
            they typically contain only pass 

        -> Implement Subclasses: Create Concrete Subclasses (Regular Classes)
        that inherit from abstract class, these Subclasses must Implement 
        all abstract methods which are defined in abstract class.
        If a subclass fails to Implement any abstract method, it will also
        become abstract class and cannot be instantiated
